VoidBar 0.6.0 is the first public release: a native SwiftUI and AppKit productivity panel for the MacBook notch that you can download and run without cloning the repository or opening Xcode.

## Download

| File | What it is |
| --- | --- |
| `VoidBar-0.6.0-arm64.dmg` | Drag-to-Applications disk image for Apple Silicon Macs |
| `VoidBar-0.6.0-arm64.dmg.sha256` | SHA-256 checksum of the disk image |

Requires macOS 15 Sequoia or later on Apple Silicon. Intel Macs can build from source; that configuration is untested.

## Install

1. Open the disk image and drag **VoidBar** to **Applications**.
2. Open VoidBar. macOS warns that it cannot verify the developer; choose **Done**, not **Move to Trash**.
3. Open **System Settings → Privacy & Security**, choose **Open Anyway** next to the VoidBar message, and confirm with your password.

The same warning can appear once more for the Now Playing helper. Choose **Done**; if macOS keeps the helper blocked, VoidBar controls Apple Music and Spotify directly and every other feature works as usual.

Verify the download from the folder that contains both files:

```bash
shasum -a 256 -c VoidBar-0.6.0-arm64.dmg.sha256
```

## Signing and notarization

This build is **ad-hoc signed**. It is **not** signed with an Apple Developer ID and **not** notarized by Apple, which is why Gatekeeper asks for the steps above. The disk image is built from the `v0.6.0` tag by GitHub Actions, which also publishes a build provenance attestation:

```bash
gh attestation verify VoidBar-0.6.0-arm64.dmg --repo xand0dev/VoidBar
```

## Included in this release

- **Everything in the panel:** media controls, file shelf, clipboard history, notes, snippets, translation, calendar, Pomodoro, weather, TickTick tasks, teleprompter, and system monitor.
- **English ↔ Ukrainian translation** through Apple's on-device Translation framework. Ukrainian text goes to English, everything else to Ukrainian.
- **Media progress that holds its place:** opening the notch no longer snaps the progress bar back to a stale Now Playing position.
- **Customizable tabs:** hide tabs and change their order in Preferences.
- **English and Ukrainian interface and documentation.**

## New in the release process

- Downloadable disk image and SHA-256 checksum, verified after every build (image integrity, layout, bundle version, localizations, and code signature).
- Pull-request CI now packages and verifies the disk image, not only the app bundle.
- The README walkthrough, media screenshot, and social preview were re-recorded from the real panel with an invented track and original cover art, replacing captures that showed third-party album artwork and brands.

## Privacy

No analytics, advertising, accounts, or VoidBar server. Weather contacts `ipapi.co` and Open-Meteo after you first open that tab, TickTick fetches the iCal URL you configure, Spotify artwork may load from Spotify's CDN, and macOS may download translation languages from Apple. Clipboard history stays in memory. The complete map is in [PRIVACY.md](https://github.com/xand0dev/VoidBar/blob/v0.6.0/PRIVACY.md).

## Known limitations

- Not notarized; first launch needs **Open Anyway** as described above.
- Apple Silicon only in the published build.
- The system-wide Now Playing feed relies on a helper loaded into `/usr/bin/perl` because macOS 15.4+ restricts MediaRemote access. If macOS blocks that helper, media control falls back to Apple Music and Spotify.
- Translation needs the English and Ukrainian language packs installed in **System Settings → General → Language & Region → Translation Languages**.
