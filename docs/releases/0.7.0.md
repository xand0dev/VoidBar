## What's new

- **Overview.** The panel opens here. While music plays, the player takes a large card; around it sit widgets for your coding agents' limits, the latest clipboard entries and snippets (each copies with one click), the focus timer, the latest note, shelf files, tasks, meetings, weather, and system load. A widget only appears while its tab is on and it has something to show. Choose and order widgets in **Preferences → Overview**.
- **Live island.** While music plays or a timer runs, the notch grows a wing on each side: the cover or a progress ring on the left, a live equalizer or the countdown on the right.
- **Make it yours.** **Preferences → Appearance** offers six accent presets, including a blood red, or any colour you pick. The aurora can follow what is on screen, use only your accent, or be off, with adjustable strength. Opening animations can be turned off, and Reduce Motion always turns them off. The panel itself stays black so it blends into the notch.
- **Claude Code and Codex limits.** A new Usage tab shows the five-hour and weekly windows, how much of each is used, and when each resets. Codex works out of the box. For Claude Code, copy one status-line setting from the tab. Everything is read locally; there is no sign-in and no network request. The tab is off by default.
- **A full redesign.** Every tab now uses lit cards with hairline edges, one accent colour, SF Rounded numerals, and shared components. The panel is a little larger, opens with a choreographed animation, and has a soft aurora behind its content. Preferences has been rebuilt too.

## Upgrading from 0.6.0

Open the disk image and replace VoidBar in Applications. Your tabs, notes, snippets, and settings carry over. The Overview is inserted at the front of your tab rail, and the Usage tab stays off until you turn it on.

## Install

1. Open the disk image and drag **VoidBar** to **Applications**.
2. Open VoidBar. macOS warns that it cannot verify the developer; choose **Done**, not **Move to Trash**.
3. Open **System Settings → Privacy & Security**, choose **Open Anyway** next to the VoidBar message, and confirm with your password.

The same warning can appear once more for the Now Playing helper. Choose **Done**; if macOS keeps the helper blocked, VoidBar controls Apple Music and Spotify directly and every other feature works as usual.

Verify the download from the folder that contains both files:

```bash
shasum -a 256 -c VoidBar-0.7.0-arm64.dmg.sha256
```

## Signing and notarization

This build is **ad-hoc signed**. It is **not** signed with an Apple Developer ID and **not** notarized by Apple. The disk image is built from the `v0.7.0` tag by GitHub Actions, which also publishes a build provenance attestation:

```bash
gh attestation verify VoidBar-0.7.0-arm64.dmg --repo xand0dev/VoidBar
```

## Privacy

Nothing new leaves your Mac. The Usage tab reads Codex's own session logs and a small file written by the Claude Code status line bridge, which holds only the two limit windows. Appearance and Overview choices are stored in macOS preferences. The full map is in [PRIVACY.md](https://github.com/xand0dev/VoidBar/blob/v0.7.0/PRIVACY.md).

## Known limitations

- Not notarized; the first launch needs **Open Anyway**.
- Apple Silicon only in the published build.
- The Claude Code card only updates from `claude` CLI sessions, because Claude Code runs status-line commands in its terminal interface.
- The system-wide Now Playing feed relies on a helper that macOS may block; media control then falls back to Apple Music and Spotify.
