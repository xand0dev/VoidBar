**Временные заметки** — справа появился второй столбец иконок, и открывают его
они. Быстро записать телефон из разговора, кусок ссылки, мысль на полчаса;
вернуться, удалить или унести через буфер обмена. Наведение сразу даёт каретку —
если заметок нет, пустая создаётся сама, — а пустые заметки убирают себя при
уходе с вкладки. Это сознательно не работа с заметками: ни папок, ни
форматирования, ни поиска — замена редактору с безымянным буфером, который
держат открытым ради «записать на время». Всё переживает перезапуск.

**Крестик на полке больше не прячется.** Удаляешь карточки подряд, не двигая
мышью, — следующая подъезжает под курсор уже с крестиком. Раньше он появлялся
только после случайного шевеления, и клик вместо удаления выделял карточку.
